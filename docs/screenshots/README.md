# Screenshots

Drop images here and reference them from the main `README.md`, e.g.:

```markdown
![The suggestion bar in Chrome](docs/screenshots/chrome-suggestions.png)
```

Suggested shots, roughly in the order they'd help a first-time visitor:

1. **The bar itself** — mid-sentence, a few candidates showing, in whatever theme looks best.
2. **One of the seven themes side by side** — or a small grid of two or three, to show the visual range.
3. **The bar in a browser** (Chrome/Edge/Brave) — this is the thing that took the longest to build and is
   easy to disbelieve without seeing it.
4. **The bar in Word** — same reason, different application.
5. **The Settings window** — the light/dark pin and fixed-width controls are new; worth showing they exist.
6. **A phrase suggestion** ("looking forward to", "let me know") — shows the multi-word feature is real,
   not just single words.
7. **An emoji suggestion** — small thing, but immediately legible in a screenshot.
8. **Personal vocabulary in Settings** — showing a custom entry, generic content only (see below).

## Before adding a screenshot

- **Don't capture anything personal.** No real names, addresses, email accounts, or document contents that
  are actually yours. Type placeholder text for the shot — "Alexandra Fairbourne Reed" and
  "example.org", the same style already used in the test fixtures, works fine.
- **Keep files reasonably small.** PNG at the actual UI size is normally under a few hundred KB; there's no
  need to ship a 4K screen capture of a 400×80 pixel bar. Crop tight.
- **Name files by what they show**, not by date or a screenshot tool's default name —
  `chrome-suggestions.png`, not `Screenshot 2026-08-15 031204.png`.
